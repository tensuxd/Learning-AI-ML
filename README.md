# 🤖 AI / ML Learning Journey

> Personal learning repository — from Python basics to LLM engineering.

---

## 🎯 Goal

Get a job as a **Trainee AI/ML Engineer** by building real skills through hands-on projects, not just theory.

---

## 🗺️ Roadmap

### Phase 0 — Foundation
| Topic | What I learn |
|---|---|
| Python basics | Variables, loops, functions, files, exceptions |
| Mini-math | Averages, matrices, functions — intuition level |
| NumPy | Arrays, math operations on data |
| Pandas | DataFrames, filtering, cleaning datasets |

### Phase 1 — First ML Steps
| Topic | What I learn |
|---|---|
| Matplotlib / Seaborn | Data visualization, distributions, correlations |
| scikit-learn | Linear regression, decision trees, train/test split |
| Model evaluation | Accuracy, precision, recall, overfitting |
| Kaggle datasets | Working with real open data |

### Phase 2 — Deep Learning & LLMs
| Topic | What I learn |
|---|---|
| PyTorch basics | Tensors, autograd, building a neural net from scratch |
| Deep learning concepts | Loss, backprop, activations, optimizers |
| Hugging Face | Pipelines, tokenizers, inference, fine-tuning |
| LLM APIs | OpenAI / Claude API, system prompts, chain-of-thought |
| Prompt engineering | Structuring prompts, RAG basics |

### Phase 3 — Junior Level
| Topic | What I learn |
|---|---|
| Git | Version control for ML projects |
| Docker | Containerizing models |
| FastAPI | Serving ML models as an API |
| Specialization | CV / NLP / LLM agents — pick one |

## 🧪 Pet Projects

### Pet Project #1 — Classic ML
- Take an open dataset (Titanic / Housing Prices)
- Clean data → train a model → evaluate → save results
- Stack: Python, Pandas, scikit-learn

### Pet Project #2 — LLM / Deep Learning *(after Phase 2)*
- RAG chatbot / image classifier / LLM agent
- Deploy to Hugging Face Spaces or Railway
- Stack: PyTorch / Hugging Face / FastAPI
